# دليل لوحة إدارة المنصة المركزية

رابط الواجهة المنشورة يختلف عن رابط API. الواجهة تتصل بقاعدة `environment.apiUrl`
وتضيف JWT تلقائياً للطلبات المحمية. إذا ظهرت `401` فابدأ بفحص الجلسة/الصلاحية؛ وإذا
ظهرت `500` أو `503` فافحص API وسجل الخادم، لا الواجهة فقط.

## استخدام عام في كل شاشة

- الجداول تعمل بترقيم Server-side: استخدم السابق/التالي وحجم الصفحة `10/20/50/100`.
  لا تحاول تحميل كل السجلات في المتصفح.
- زر الإنشاء أو التعديل يفتح نموذجاً؛ الحفظ هو العملية التي تغير البيانات. اقرأ
  التحقق ورسالة التأكيد قبل الحفظ.
- لا تضف CRUD عاماً إلى السجل المالي أو Audit أو Jobs/Outbox أو سجل النسخ؛ هذه سجلات
  تاريخية/تشغيلية.
- المساعد التشغيلي يظهر في كل شاشة: الزر العائم، زر النجمة في الشريط العلوي، أو
  `Ctrl+K`. يشرح الشاشة ويبحث عن الإجراء المسموح للمستخدم فقط.

## الشاشة الرئيسية

| الشاشة | الصلاحية | الغرض | الأزرار والقرارات الرئيسية |
|---|---|---|---|
| `/dashboard` | `ManagePlatformReports` | رؤية تنفيذية لصحة المنصة والمدفوعات والاشتراكات والتنبيهات. | افتح التنبيه أو طلب الدفع أو السجل المصدر قبل أي قرار؛ الأرقام ليست بديلاً عن الدليل التفصيلي. |
| `/reports` | `ManagePlatformReports` | تقارير ومؤشرات مجمعة. | استخدمها للاكتشاف والتحليل، ثم تحقق من المصدر (فاتورة/دفع/صالة/Audit). |
| `/alerts` | `ManagePlatformReports` | مركز التحذيرات المالية والتشغيلية والأمنية. | ابدأ بالأعلى شدة، ثم انتقل للعمليات أو السجل؛ تحديث يعيد القراءة فقط. |
| `/documentation` | `ManagePlatformReports` | مرجع وبحث داخل لوحة الإدارة يشرح المنتج والـAPI والسياسات وكل الشاشات. | استخدم البحث ثم انتقل للشاشة المقصودة؛ التوثيق لا يتجاوز صلاحيات الـBackend. |

## الصالات والاشتراكات

| الشاشة | الصلاحية | ما تعرضه | إجراءات مسموحة وآمنة |
|---|---|---|---|
| `/tenants` | `ManageTenants` | الصالات، نطاقها، مالكها وحالة تشغيلها. | **جيم جديد** يفتح الإنشاء؛ `Approve` للموافقة، `Suspend` لمنع الدخول، `Activate` للإعادة، `Archive` لإيقاف تاريخي. لا حذف مباشر. |
| `/subscriptions` | `ManageTenants` | دورات الـSaaS وحالتها وتواريخها وخطة كل صالة. | راجع الحالة/النهاية/الفاتورة قبل transition أو extend. تمديد يضيف أياماً، وليس دورة جديدة؛ التعليق لا يوقف الزمن. |

قبل إيقاف صالة أو اشتراك، راجع أثر القرار: إيقاف الصالة يمنع الدخول حتى مع اشتراك صالح؛
انتهاء الاشتراك يمنع الميزات المدفوعة حتى مع صالة نشطة.

## الخطط والميزات والحدود

| الشاشة | الصلاحية | ما تعرضه | الأزرار/القواعد |
|---|---|---|---|
| `/plans` | `ManagePlans` | باقات الـSaaS ومدتها وسعرها وعملتها والحدود والميزات. | **باقة جديدة** و**تعديل** لتغيير القالب المستقبلي. لا تغير Snapshot اشتراك فعال؛ خفض الخطة للدورة التالية. |
| `/features` | `ManagePlans` | كتالوج الميزات: `FeatureKey`، الاسم، Module، مجاني/مدفوع، Global status، Quota وLifecycle. | **ميزة جديدة** لتعريف تجاري؛ **تعديل**؛ **أرشفة** بدلاً من حذف التاريخ. FeatureKey ثابت بعد الإنشاء. |
| `/feature-overrides` | `ManagePlans` | استثناء ميزة لصالة بعينها مع السبب وبداية/نهاية. | **استثناء جديد** أو تعديل الاستثناء. لا يتجاوز Global Disable أو الصالة الموقوفة. |
| `/quota-definitions` | `ManagePlans` | تعريف نوع حد وموارد الميزة. | **حد جديد** أو تعديل/تعطيل. لا تعبث بحجوزات الاستخدام أو Snapshot تاريخي. |
| `/feature-dependencies` | `ManagePlans` | علاقات feature requires feature. | **إضافة اعتمادية**؛ إزالة علاقة إعداد فقط بعد مراجعة عدم وجود دائرة. |

ترتيب حسم الإتاحة: `Global Disable → Subscription Access → Tenant Override → Plan
Feature → Default Deny`. لا تعتمد شاشة على هذا الترتيب وحدها؛ الـBackend هو صاحب
القرار النهائي.

| `/invoices` | `ManagePlatformReports` | فواتير SaaS المرقمة والخصم والضريبة والعملة والمبلغ النهائي. | قراءة/بحث فقط. رقم الفاتورة فريد متسلسل ولا يعاد استخدامه؛ التصحيح بعكس مالي جديد. |

## الحوكمة والأمن والتشغيل

| الشاشة | الصلاحية | ما تعرضه | الأزرار/القواعد |
|---|---|---|---|
| `/administrators` | `ManagePlatformReports` | حسابات فريق المنصة وحالة الحساب. | **مشرف جديد**، تفعيل/تعطيل. امنح أقل دور ممكن ولا تشارك الحسابات. |
| `/roles` | `ManagePlatformReports` | الأدوار وصلاحيات المنصة. | افتح محرر الصلاحيات ثم احفظ بعد المراجعة. `ManagePlatform` وصول كامل. |
| `/audit-logs` | `ManagePlatformReports` | من نفذ ماذا ومتى وعلى أي كيان. | بحث وإعادة ضبط فلتر فقط؛ قراءة غير قابلة للتعديل أو الحذف. |
| `/operations` | `ManagePlatformReports` | `Jobs` و`Outbox`، الحالات وإعادة المحاولة والأخطاء. | قراءة/متابعة فقط. لا تحذف records؛ اربط الفشل بالتنبيهات وAudit. |
| `/backups` | `ManagePlatformBackups` | حالة خدمة النسخ، قائمة الملفات وحالة الإنشاء والتنزيل. | **إنشاء نسخة** بعد تأكيد، **تنزيل** بعد اكتمالها. حفظ الملف خارج مسار عام؛ 404 للتنزيل يعني غالباً خادم بإصدار API قديم. |

## مصفوفة الحالات والإجراءات

| الكيان | لا تفعل | افعل بدلاً منه |
|---|---|---|
| Tenant/Administrator | حذفاً يفقد التاريخ | Activate/Suspend/Archive أو Disable. |
| Tenant Subscription | تعديل Snapshot أو نقل حالة عشوائي | Transition مسموح أو Renew/Upgrade/Extend مسجل. |
| Invoice/Subscription Payment | تعديل أو حذف عملية معتمدة | عملية عكسية جديدة موثقة. |
| Payment Request | تعديل بعد القرار | اعتماد/رفض بسبب؛ أنشئ طلباً جديداً عند الحاجة. |
| Audit/Outbox/Jobs/Backup history | حذف أو تعديل السجل | بحث/مراقبة/أرشفة وفق سياسة الخادم فقط. |
| Feature | تغيير FeatureKey أو حذف تاريخ | تعديل البيانات التجارية أو Archive. |

## المساعد التشغيلي الذكي

كتالوج المساعد في `LogiFit_Platform_Admin_Dashboard/src/app/shared/assistant/` ويضم
دليلاً لكل مسار محمي في اللوحة. البحث يقبل عبارات مثل `إضافة صالة`، `إيقاف صالة`،
`تجديد`، `موافقة دفع`، `نسخة احتياطية` و`صلاحيات`. لا يتصل بخدمة ذكاء اصطناعي خارجية
ولا ينفذ Mutation بلا نموذج أو تأكيد وصلاحية. عند إضافة شاشة أو زر، حدّث الكتالوج
والدليل في نفس التغيير.
